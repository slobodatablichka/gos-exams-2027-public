# Знаки богослужебных разрядов

SVG-пиктограммы, вычерченные по образцам в заголовке таблицы «Вечерня и утреня. Состав службы» (изображение пользователя от 21 ноября 2026 года). Контуры выполнены вручную по исходному растровому образцу. Формат SVG, viewBox 64×64, единая толщина линии 3.1; цвет определяется `currentColor`, фон прозрачный.

## Файлы

| Разряд | Файл | Знак |
|---|---|---|
| Шестеричная | `shesterichnaya.svg` | фигурный знак с тремя точками |
| Славословная | `slavoslovnaya.svg` | тот же фигурный знак (как на таблице) |
| Полиелейная | `polieleynaya.svg` | прямой крест |
| Бденная среднего святого | `bdennaya-srednego-svyatogo.svg` | крест над нижней дугой |
| Бденная великого святого | `bdennaya-velikogo-svyatogo.svg` | крест в круге |
| Господский праздник | `gospodskiy-prazdnik.svg` | крест в круге |
| Богородичный двунадесятый праздник | `bogorodichnyy-dvunadesyatyy.svg` | крест в круге |

Различия между разрядами сохраняются через подписи и контекст: в предоставленной таблице некоторые пиктограммы **графически совпадают**. Не придумывать разницу знаков там, где её нет на оригинале. При совпадении нескольких знаков в одной ячейке показывать их последовательно, не сливать.

Публикуемые SVG являются чистой векторной графикой: нет внешних шрифтов, растровых фрагментов, ссылок, JS или встроенных стилей. Контуры могут масштабироваться без потери качества. Для доступности используется `title` / `aria-label`, а рядом с пиктограммой в тексте показывается название вида службы.
