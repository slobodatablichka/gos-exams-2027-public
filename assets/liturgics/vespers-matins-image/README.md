# Вечерня и утреня — изображение и интерактивный просмотр

## Источник

Загруженная таблица `0203011007_Вечерня-и-утреня-Состав-службы.png`, 725×1046 px, SHA-256 оригинала `1526c6b78e41c39528e772be97d851a2665692a18e990e1f7a7a81eeec1ac080`.

Для веб-показа из исходного изображения создан высококонтрастный 1-битный экземпляр с порогом 170. Он сохраняет все 17 вариантов служб, строки вечерни и утрени и печатные условные знаки. Техническое отличие: оттенки серого исходника переведены в чёрный/белый; это **не** текстовая посимвольная транскрипция.

- Размер: 725×1046, `PIL.Image.convert('1')`; сырые данные 95 186 байт (91 байт на строку).
- Упаковка: zlib/deflate (zopfli, 15 итераций), 25 037 байт; SHA-256 бинарного сжатого потока `de25a752b3c3376078a36e214ab1f2af82bf757010866b4244f6d1b96c197138`.
- Base64: 33 384 символа, части `part-01.txt`…`part-07.txt` длиной 5000×6 + 3384.
- Порядок чтения строк — сверху вниз; координаты колонок и строк находятся в `../vespers-matins-viewer.js`.
- Декодирование: `atob` → `DecompressionStream('deflate')` → 1 бит на пиксель (1 — белый) → Canvas.
- Представления: цельная таблица, выбранная колонка с боковыми подписями, сравнение каждой строки по 17 колонкам.
- SVG-значки — `../service-signs/`.
