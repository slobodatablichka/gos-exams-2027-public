# Литургика — 2027. Вопрос №2. Воскресное всенощное бдение

**Официальный вопрос:** Воскресное богослужение: порядок всенощного бдения (условия совершения богослужения на выбор комиссии: период (Октоих/Постная Триодь/Цветная Триодь), глас, празднуемый святой, святой храма).

**Уровень L1 — памятка перед ответом.**

1. Сначала период, глас, память святого, храм.
2. Бдение: **великая вечерня → утреня → 1-й час**.
3. Вечерня: стихиры, вход, прокимен, лития; утреня: Евангелие, каноны, хвалите, славословие.
4. Триодь меняет состав песнопений; пример одной даты не универсален.

**Результат:** правильная последовательность **вечерня → утреня → часы** с объяснением особенностей выбранного случая.
