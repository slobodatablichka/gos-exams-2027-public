# Литургика — 2027. Вопрос №6. Страстная и Светлая седмицы

**Официальный вопрос:** Богослужение Страстной/Светлой седмицы (один из дней на выбор комиссии).

**L1 — памятка для быстрого повторения.**

1. Укажи **конкретный день** Страстной или Светлой седмицы.
2. Великий пяток: **утреня Страстей (12 Евангелий) → царские часы → вечерня с Плащаницей**.
3. Великая суббота — другой чин; Светлая седмица — пасхальная последовательность.
4. Нельзя переносить схему одного дня на всю седмицу.

**Помни:** служба определяется заданным днём и совпадениями; нельзя переносить чужой вариант без исправления.

**Контроль источников:** Страстная: Триодь Постная, ч. 2; Светлая: особый чин, клиросная Цветная Триодь неполная. [Сверить с L3](q06-l3.html).

**Для подготовки устного ответа:** [L2](q06-l2.html). **Для подробной сверки:** [L3](q06-l3.html).
