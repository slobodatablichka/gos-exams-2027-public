# Литургика — 2027. Вопрос №10. Субботние заупокойные богослужения

**Официальный вопрос:** Субботнее заупокойное богослужение литургического года (один из дней на выбор комиссии).

**L1 — памятка для быстрого повторения.**

1. Назови субботу: **Мясопустная / Троицкая / постовая**.
2. Вечерня — свои стихиры; утреня — **Непорочны, заупокойные песнопения и канон**.
3. Часы и Литургия — особые тропари/чтения.
4. **Панихида не заменяет** последование субботней службы.

**Помни:** служба определяется заданным днём и совпадениями; нельзя переносить чужой вариант без исправления.

**Контроль источников:** Мясопустная / великопостные / Троицкая: различить период; лития ≠ полная служба. [L3](q10-l3.html).
