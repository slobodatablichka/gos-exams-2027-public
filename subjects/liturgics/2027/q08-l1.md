# Литургика — 2027. Вопрос №8. Рождество, Богоявление, Благовещение

**Официальный вопрос:** Богослужение Рождества Христова, Богоявления, Благовещения Пресвятой Богородицы (один из праздников на выбор комиссии).

**L1 — памятка для быстрого повторения.**

1. Сначала выбери **один** из трёх праздников.
2. Рождество: **царские часы навечерия → великое повечерие с литией → утреня → 1-й час → Литургия**.
3. Богоявление — особые часы и освящение воды.
4. Благовещение — обязательно проверить соединение с Великим постом.

**Помни:** служба определяется заданным днём и совпадениями; нельзя переносить чужой вариант без исправления.

**Контроль источников:** Рождество / Богоявление / Благовещение: отдельные календарные правила и Минеи. [L3](q08-l3.html).
