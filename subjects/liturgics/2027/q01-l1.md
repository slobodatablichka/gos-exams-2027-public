# Литургика — 2027. Вопрос №1. Седмичные и субботние службы Октоиха

**Официальный вопрос:** Богослужения седмичные и субботние периода пения Октоиха (условия совершения богослужения на выбор комиссии: день недели, глас, празднуемый святой, святой храма).

**Уровень L1 — памятка перед ответом.**

1. Установи **день, глас, святого и разряд**.
2. Выбери схему: вседневная / славословная / полиелейная; субботу разбирай отдельно.
3. Собери **вечерню → утреню → часы**; отметь источники стихир, канонов, тропарей, кондаков.
4. Контроль: не добавляй полиелей и великое славословие без основания.

**Результат:** правильная последовательность **вечерня → утреня → часы** с объяснением особенностей выбранного случая.

**Контроль источников:** Октоих + Минея + Часослов; глас, разряд, суббота проверяются отдельно. При сомнении — [L3](q01-l3.html), без догадок.
