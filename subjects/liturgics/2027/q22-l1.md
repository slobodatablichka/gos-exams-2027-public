# Литургика — 2027. Вопрос №22. Погребение усопших

**Официальный вопрос:** Погребение усопших: виды и порядок последований, содержание молитв, толкование чинов.

**L1 — краткие тезисы.**

1. Смысл: **молитва об усопшем и надежда на воскресение**.
2. Лития/панихида ≠ полное отпевание.
3. Миряне: псалмы, канон, чтения, разрешительная молитва, целование, погребение.
4. Отдельные чины: младенцы, монашествующие, священники; **пасхальный** чин особый.

**Экзамен:** по этим опорным словам восстанови связный ответ из L3.
