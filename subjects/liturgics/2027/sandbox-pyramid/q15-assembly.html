На телефоне: удерживайте кирпичик около четверти секунды, затем тяните. Для прокрутки проводите пальцем по самим кирпичикам до удержания. Для просмотра — коротко нажмите. При открытой карточке Песочница не перемешивается. Клавиатура: Enter — просмотр; пробел — выбрать для переноса; стрелки — выбрать место; Enter — разместить; Esc — отменить.
