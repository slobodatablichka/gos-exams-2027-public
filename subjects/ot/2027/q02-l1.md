# Ветхий Завет — 2027. Вопрос №2. L1

**Официальная формулировка:** Основные версии текста Ветхого Завета. Рукописи Мертвого моря (библейские), их значение для библеистики.

## Опорный план устного ответа

- Различать первоначальный текст, рукописный список, редакцию и перевод; большая часть ВЗ — еврейский текст, часть — арамейский.
- Масоретский текст: еврейская традиция с огласовками; средневековые списки передают более древний текст.
- Самарянское Пятикнижие: самостоятельная древняя текстовая традиция, особенно ценно при сравнении разночтений.
- Септуагинта: древнегреческий перевод, начатый с Пятикнижия; значение для Нового Завета и Церкви.
- Иные версии: Акила, Симмах, Феодотион; «Гекзаплы» Оригена; таргумы, Пешитта, Вульгата; отличать Синодальный перевод.
- Кумран: находки у Мёртвого моря с 1947 года; библейские рукописи отдельно от общинных сочинений.
- Значение: свидетельства древности и преемственности текста одновременно с его реальным разнообразием; конкретные чтения сверяют по рукописям.
- Итог: история текста помогает точному церковному толкованию, но сама по себе не заменяет его.
