# Учебные материалы

Здесь удобно выбирать материалы по порядку: **занятие → экзаменационный вопрос → уровень L3, L2 или L1**.

**L3** — статья для понимания темы; **L2** — связный ответ для устного экзамена; **L1** — тезисы для повторения.

**[План докладчиков для групп 5, 6 и 7](../assignments.html)** — выбрать свою группу и дату; распределения на все 23 занятия.
