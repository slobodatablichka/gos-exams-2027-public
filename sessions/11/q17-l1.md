# ДБ №17. Афтартодокетизм · L1

1. Кенозис: добровольное уничижение Сына без утраты Божества (Флп. 2:6–8).
2. Неукоризненные страсти — голод, усталость, боль, страх смерти, смертность; не греховные пороки.
3. Афтартодокетизм, VI век: Юлиан Галикарнасский считал страдания несвойственными природе тела Христа; спор с Севиром Антиохийским.
4. Первое значение тления — страдательность и смертность: Христос действительно страдал и умер.
5. Второе — посмертный распад: тело Христа не увидело тления (Деян. 2:27, 31).
6. Естественность = настоящая способность человеческого естества страдать; добровольность = свободное принятие смерти (Ин. 10:18).
7. После Воскресения — прославленное нетленное тело; Христос безгрешен.

**Основание:** , ; прот. Олег Давыденков, *Догматическое богословие* (БПДС).
